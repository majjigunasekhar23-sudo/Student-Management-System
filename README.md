# Student Management System

## Project Description
The Student Management System is a C++ application developed to manage student records efficiently. It allows users to add, display, search, update, and delete student information using Object-Oriented Programming and file handling.

## Features
- Add new student records.
- Display all student details.
- Search students by ID.
- Update student information.
- Delete student records.
- Save student data permanently using file handling.

## Technologies Used
- **Programming Language:** C++
- **Concepts:** Classes, Objects, Arrays, Functions, Loops, Conditional Statements and File Handling.

## Files Included
- `StudentManagement.cpp` – Main source code.
- `students.txt` – Stores student records automatically.

## How to Run
1. Open the C++ source code in VS Code or any C++ compiler.
2. Compile and run the program.
3. Select an option from the menu.
4. Perform the required student management operations.

## Expected Outcome
A simple application that efficiently manages student information and maintains records using file handling.

## Conclusion
This project demonstrates the practical implementation of C++ programming, Object-Oriented Programming and file handling concepts.
